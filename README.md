# Magicalorbs Games - Review & Rating Hub 🎮

A streamlined, modern web hub designed for **Magicalorbs Pvt. Ltd.** to collect 5-star ratings and authentic reviews on Google Play in under 10 seconds.

## ✨ Features
- **Zero Friction (1-Tap Copy & Rate):** Automatically copies pre-crafted review text and launches Google Play rating dialog directly.
- **Android Deep Link Integration:** Opens the native Google Play Store app directly using `market://` intent without requiring in-browser sign-in.
- **Customizable Moods & Variations:** Quick preset chips for instant review customization or shuffle.
- **WhatsApp Direct Sharing:** Easily share with friends and community with pre-filled invitations.
- **Vercel Ready:** Fully configured with `vercel.json` and static routing.

## 🚀 Deployment
Deploy to Vercel in 1 click:
1. Push to GitHub (`main` branch)
2. Import repository into [Vercel](https://ipoprock.github.io)
3. Vercel automatically deploys `index.html` with zero build configuration.
